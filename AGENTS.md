# Project structure

The workspace root is the active project. Run frontend commands here; React source lives in `src/`. The Python service lives in `backend/`; run its commands there. Do not recreate the legacy `frontend/` or nested `code_kavach/` directories.

Keep the requirements and planning documents (`context.md`, `prd.md`, `breakdown.md`, `frontend.md`), original problem statement, public dataset, and `rough_images/` design references. See README.md for setup and checks.
